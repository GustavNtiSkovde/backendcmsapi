CMS API

Pages with Swedish and English translations

Overview Data model Get pages Create a page Update a translation Delete a page Errors Good to know

Overview

One endpoint handles everything. Reading uses GET. Creating, updating and deleting use POST with a JSON body and an action field.

https://cmsapi.ntigskovde.se/gustav/api.php

Every response is JSON. A request worked if success is true. Send Content-Type: application/json on every POST.

Data model

A page is one record with a category, optional image, and any number of translations (one per language). Languages in the database are Svenska and Engelska.

{
  "page_id": 12,
  "created_at": "2026-10-09 14:30:00",
  "category": "News",
  "media": {
    "file_path": "uploads/pic.png",
    "file_name": "pic.png",
    "file_type": "image/png",
    "alt_text": "A picture"
  },
  "translations": [
    { "lang": "Svenska",  "title": "Hej världen", "slug": "hej-varlden", "content": { "text": "Svensk text" } },
    { "lang": "Engelska", "title": "Hello world", "slug": "hello-world", "content": { "text": "English text" } }
  ]
}

media is null when the page has no image. content is an object with a text key.

GETGet pages

/api.php

Returns a list of pages, or one page when you pass id, slug or title. All parameters are optional and can be combined.

ParameterDescription
idPage ID. Returns a single page.
slugReturns the page that has a translation with this slug (in any language).
titleReturns the page that has a translation with exactly this title.
langsv, en, Svenska, Engelska or the numeric language ID. Only that translation is included, and pages without it are left out.
categoryCategory name (News) or numeric ID.

If several single-page parameters are sent, the priority is id, then slug, then title.

Examples

GET /api.php                          all pages, all translations
GET /api.php?lang=sv                  all pages, Swedish only
GET /api.php?category=News&lang=en    English news pages
GET /api.php?id=12                    one page
GET /api.php?slug=hello-world         one page found by slug

Response: list

{ "success": true, "data": [ { …page… }, { …page… } ] }

Response: single page

{ "success": true, "data": { …page… } }

A single-page lookup with no match returns status 404.

POSTCreate a page

/api.php   "action": "CREATE"

Creates one page with one or more translations. CREATE is the default if action is left out.

FieldTypeDescription
categorystring, requiredCategory name. Created if it doesn't exist yet.
translationsarray, requiredEach item has lang, title and content. Items missing lang or title are skipped. At least one valid item is needed.
imgNamestring, optionalFile name such as pic.png. Stored as uploads/pic.png.
imgAltstring, optionalAlt text for the image.

Request

{
  "action": "CREATE",
  "category": "News",
  "imgName": "pic.png",
  "imgAlt": "A picture",
  "translations": [
    { "lang": "Svenska",  "title": "Hej världen", "content": "Svensk text" },
    { "lang": "Engelska", "title": "Hello world", "content": "English text" }
  ]
}

Response

{ "success": true, "message": "Page created with translations!", "page_id": 12 }

The page and all its parts are saved together. If anything fails, nothing is saved.

POSTUpdate a translation

/api.php   "action": "UPDATE"

Edits one language of a page. If the page has no translation in that language yet, one is added, which is how you add a missing Swedish or English version later. Other languages are not touched.

FieldTypeDescription
page_idinteger, requiredThe page to change.
langstring, requiredSvenska or Engelska.
titlestring, optionalNew title. The slug is regenerated from it. Required when adding a new translation.
contentstring, optionalNew content. Left unchanged if omitted.

Request

{ "action": "UPDATE", "page_id": 12, "lang": "Engelska", "title": "Hello again", "content": "New text" }

Response

{ "success": true, "message": "Translation saved!" }

POSTDelete a page

/api.php   "action": "DELETE"

Deletes the page with all its translations, its category link and its image link. The image record in the media table is kept.

{ "action": "DELETE", "page_id": 12 }

Response

{ "success": true, "message": "Site deleted successfully!" }

Errors

Errors always have success: false and a message.

{ "success": false, "message": "Page not found." }
StatusWhen
400A required field is missing, or action is not CREATE, UPDATE or DELETE.
404The page doesn't exist, or a single-page lookup found nothing.
500Database error. The message says what failed.

Good to know

There is no authentication. Anyone who knows the URL can create, change and delete pages. Add a login or an API key before using this on a public site.

Slugs

Slugs are generated from the title: lowercase, å ä ö become a a o, and anything other than letters, digits and hyphens becomes a hyphen. Slugs are not unique, so two pages with the same title share a slug.

Images

The API only stores the file name and path. It does not upload the file, so put the image in the uploads/ folder yourself. Each path can be used once, so a second page can't reuse the same image name.

Fetch example

const res = await fetch("api.php", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ action: "DELETE", page_id: 12 })
});
const result = await res.json();
if (!result.success) console.error(result.message);

curl example

curl -X POST https://cmsapi.ntigskovde.se/gustav/api.php \
  -H "Content-Type: application/json" \
  -d '{"action":"UPDATE","page_id":12,"lang":"Svenska","title":"Ny titel"}'
